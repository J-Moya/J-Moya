## Featured portfolio project

### 📊 Business Process & Data Quality Analytics

**Python · SQL · SQLite · KNIME · Power BI · DAX**

An end-to-end analytics project built around **50,000 fully synthetic business service requests**. It explores operational performance, SLA compliance, incorrect request assignment, data-quality issues, reopened tickets, and backlog aging.

The workflow covers:

1. Synthetic dataset generation, iterative testing, and validation in **Python**.
2. Data preparation and KPI analysis with **Pandas**.
3. Analytical queries and root-cause investigation using **SQL / SQLite**.
4. Exception detection and data-quality checks with **KNIME**.
5. Interactive reporting and DAX measures in **Power BI**.

**What this demonstrates:** combining technical implementation with process-performance analysis and actionable business recommendations.

> **Data privacy:** The dataset is synthetic. It does not contain real Roche information, employee data, or confidential business records.

🔗 **[Explore the project repository](https://github.com/J-Moya/business-process-analytics)**
